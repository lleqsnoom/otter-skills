---
description: Resolve issues from a fix or review plan — read, edit, verify, mark complete
argument-hint: [fix plan path or run folder]
---

Load the o-fix skill (`skills/o-fix/SKILL.md`) and run it end to end.

The one thing you must provide: **the fix plan** — a run folder's `E<nn>-fix-plan.md` or `E<nn>-review-plan.md`, named by `$ARGUMENTS`. If it is empty, the most recent plan in the current run folder is the one to work through.
